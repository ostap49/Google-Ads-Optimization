Connect with Google

One-click authorization for Google Ads + Merchant Center. Sign in with the Google account that manages your MCC — the refresh token is saved on the server automatically (no OAuth Playground needed).

Увійти через Google

Requires the redirect URI https://ads.ostap49.marketing/api/oauth/callback to be added in Google Cloud Console → Credentials → your OAuth client.

Google Ads Credentials

Paste your google-ads.yaml configuration below. Get credentials from Google Ads API.

Environment Variables (alternative)

Set these in your .env file or deployment environment:

GOOGLE_ADS_DEVELOPER_TOKEN=your_token
GOOGLE_ADS_CLIENT_ID=your_client_id
GOOGLE_ADS_CLIENT_SECRET=your_client_secret
GOOGLE_ADS_REFRESH_TOKEN=your_refresh_token
GOOGLE_ADS_LOGIN_CUSTOMER_ID=your_mcc_id
